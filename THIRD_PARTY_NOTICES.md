# Third-party notices

AEVRIX is open source, but its dependencies retain their own licenses.

This repository currently declares or evaluates the following dependency families. Exact versions, digests and licensing status must be captured before a release is promoted:

- Microsoft .NET / Windows App SDK
- MSTest / Microsoft.NET.Test.Sdk
- Python embedded distribution
- Playwright / Chromium
- Crawl4AI
- WiX Toolset (installer authoring; distribution/commercial terms must be reviewed for the selected release)
- Optional external analysis adapters such as Ghidra, radare2, Cutter, x64dbg, Binary Ninja and Malcat
- Optional local-model providers such as Ollama and independently licensed model weights

No third-party project is endorsed as part of an AEVRIX release merely because it is listed here. A release SBOM and license inventory are mandatory gates for AEVRIX 0.001.
